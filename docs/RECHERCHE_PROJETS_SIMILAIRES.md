# Recherche de Projets Open Source Similaires — Mascarade

> **Version** : `0.1.0`
> **Date** : 2026-03-21
> **Auteur** : Mistral Vibe

---

## 1. Introduction

Cette recherche vise à identifier des projets open source similaires à Mascarade pour l'orchestration d'agents et l'intégration d'IA. Les projets identifiés offrent des approches variées pour l'orchestration d'agents IA, selon les besoins en intégration, en collaboration ou en gestion de workflows.

---

## 2. Projets Identifiés

### 2.1. AutoGen

- **Description** : Framework développé par Microsoft pour l'orchestration multi-agents, permettant la collaboration entre plusieurs agents IA, la gestion de workflows complexes et l'intégration avec des applications d'entreprise.
- **Spécificités** :
  - Collaboration fine entre agents.
  - Mémoire partagée entre agents.
  - Intégration avec des applications d'entreprise.
- **Lien** : [AutoGen](https://github.com/microsoft/autogen)

### 2.2. CrewAI

- **Description** : Solution Python dédiée à l'orchestration d'équipes d'agents IA collaborant par rôles.
- **Spécificités** :
  - Orchestration d'équipes d'agents.
  - Collaboration par rôles.
  - Configuration minimale.
- **Lien** : [CrewAI](https://github.com/joaomdmoura/crewAI)

### 2.3. LangGraph

- **Description** : Framework open-source issu de LangChain, conçu pour construire des agents étatistes et orchestrés via des graphes de flux conditionnels.
- **Spécificités** :
  - Agents étatistes.
  - Orchestration via des graphes de flux conditionnels.
  - Niveau de contrôle inédit pour des workflows complexes.
- **Lien** : [LangGraph](https://github.com/langchain-ai/langgraph)

### 2.4. Semantic Kernel

- **Description** : SDK open-source de Microsoft pour intégrer des agents IA dans des applications .NET, Python et Java.
- **Spécificités** :
  - Intégration de plugins.
  - Déploiement local ou cloud.
  - Orchestration flexible.
- **Lien** : [Semantic Kernel](https://github.com/microsoft/semantic-kernel)

### 2.5. Dapr Agents

- **Description** : Projet issu de la communauté Dapr, spécialisé dans l'orchestration de microservices et d'agents IA, avec une forte intégration aux infrastructures IT existantes.
- **Spécificités** :
  - Orchestration de microservices.
  - Intégration aux infrastructures IT existantes.
  - Gestion de workflows complexes.
- **Lien** : [Dapr Agents](https://github.com/dapr/dapr)

### 2.6. Kagent

- **Description** : Développé par Solo.io, ce projet est conçu pour Kubernetes et les environnements cloud-native, permettant une orchestration d'agents IA en lien avec les infrastructures modernes.
- **Spécificités** :
  - Conçu pour Kubernetes.
  - Environnements cloud-native.
  - Orchestration d'agents IA.
- **Lien** : [Kagent](https://github.com/solo-io/kagent)

### 2.7. AgentWorkflow (LlamaIndex)

- **Description** : Framework orienté données pour concevoir des agents IA ancrés sur un contexte d'entreprise, avec une forte intégration aux bases de données et aux modèles de langage.
- **Spécificités** :
  - Orientation données.
  - Intégration aux bases de données.
  - Contexte d'entreprise.
- **Lien** : [AgentWorkflow](https://github.com/llama-index/llama-index)

### 2.8. ADK (Agent Development Kit)

- **Description** : Toolkit Python open-source présenté par Google Cloud pour développer, évaluer et déployer des agents IA avec flexibilité et contrôle, compatible avec des plateformes comme Agent Engine.
- **Spécificités** :
  - Développement d'agents IA.
  - Évaluation et déploiement.
  - Flexibilité et contrôle.
- **Lien** : [ADK](https://github.com/google-cloud/adk)
