# Archive Documentation

Ce dossier contient les documents historiques, snapshots d'etat et comptes-rendus dates.

## Regles

- Conserver les documents pour tracabilite.
- Ne pas supprimer les artefacts sans validation explicite.
- Privilegier un classement par theme ou date.

## Convention

- Les documents actifs restent hors archive.
- Les documents de contexte temporaire ou de journalisation sont deplaces ici apres consolidation.
